## 研究项目：湾区中餐馆盈利效率模型

> 一个可复现的数学模型，用来回答：在湾区开一家 10–15 桌的小型中餐馆，
> 川湘菜馆 / 面馆小吃 / 火锅，哪一种在数学上更优？
> 排除受众差异与产品差异化，只看结构性的盈利效率。

**📄 完整分析报告：[`reports/湾区中餐馆盈利效率模型.md`](reports/湾区中餐馆盈利效率模型.md)**

### 核心结论

1. **不存在业态层面的唯一最优解，但存在唯一的最优性判据**，且判据随"约束制度"切换：
   客人不够时最大化**每人次贡献毛利**；座位不够时最大化**每座位小时贡献（GOPPASH）**。
   绝大多数湾区小店终其一生都在前一个制度里——**"翻台率快"的边际价值经常是零**。

2. 满产利润密度是四个因子的**乘积**：

   ```
   Π/A  ∝   σ(座位密度) × φ/(d+τ)(周转速度) × p(1−θ)(每人次贡献) × H·D(可用时长)
   ```

   乘法结构惩罚短板：**"三项平庸"打得过"一项极强三项极弱"**。

3. **12 桌的火锅店在数学上不成立**：它的产能天花板出现在盈亏平衡点之前
   （结构可行性比 Φ = M_触顶 / M_平衡 = 0.80 < 1）。高峰已 100% 满座在赶客，账面仍在亏。

4. **换一个分母就换一个冠军**——每人次看川湘赢，每座位小时 / 每平方英尺看面馆赢。
   所以"最优"必须先说清楚"每什么"。

### 结构

```
model/params.py     参数层：宏观参数 + 三种业态规格 + 时段需求形状（含取值理由注释）
model/engine.py     引擎：L1 桌位离散事件模拟 / L2 时段需求卷积 / L3 财务 P&L
model/analysis.py   分析：因子分解、需求扫描、相位图、敏感性、蒙特卡洛、内点最优
model/charts.py     图表
run_analysis.py     驱动脚本
reports/            分析报告
outputs/            图表与 results.json
```

### 模型三层

| 层 | 做什么 | 关键输出 |
|---|---|---|
| **L1 桌位物理层** | 1 分钟步长离散事件模拟：同行人数分布 × 桌型配比 × 迎宾规则 × 放弃排队 | 座位填充率 φ、桌位吞吐、并桌率 |
| **L2 时段需求层** | 逐小时 `min(需求, 产能)` 卷积 + 排队削峰 + 流失 | 自动区分需求约束区 / 产能约束区 |
| **L3 财务层** | 完整 P&L（含维护性资本支出计提、损耗、业主机会成本） | 单位经济学、盈亏平衡、经营杠杆、ROIC |

### 免责

参数来自公开基准与行业经验值的校准，不是任何一家店的实账。
单点数值应视为量级估计；结论的稳健性来自敏感性分析与相位图的形状，而非任何单个数字。
模型按要求**排除了产品差异化**——而差异化恰恰是现实中最大的变量。
